# Assignment 4 – Forecasting Models

## Description

This assignment applies different forecasting models to a monthly time series dataset. The objective is to compare the forecasting performance of different models and identify the best-performing model based on forecast accuracy.

## Models Used

The following forecasting methods were evaluated:

- Mean
- Naive
- Seasonal Naive
- Moving Average (MA5)
- Moving Average (MA9)
- Exponential Smoothing (ETS)
- Holt-Winters

## Accuracy Measure

The models were compared using MAPE (Mean Absolute Percentage Error).

The model with the lowest MAPE was selected as the best-performing forecasting model.

## Files

- `Assignment 4.Rmd` – R Markdown file containing the analysis and code.
- `Assignment-4.html` – HTML output containing the results, graphs, and analysis.
